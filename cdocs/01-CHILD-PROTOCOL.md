# 第 1 部分：入门协议（Child-Protocol）

**读者：** 初学者与非技术人员  
**代码仓库：** [github.com/utahisnotastate/Utahx](https://github.com/utahisnotastate/Utahx)

---

## 类比：自动开张的店面

假设你在车库为柠檬水摊做了一块木招牌。

**旧方式（Nginx 等）：** 要先雇施工队、办手续、请保安、修路，别人才能看到你的招牌。配置文件里一个标点错误就可能锁门停业，还要读几天到几周的手册。

**Utahx 方式：** 把招牌放进“魔法盒子”，按一个按钮，摊位就出现在繁忙街道上，保安也已就位。

Utahx 就是网站的这个“魔法盒子”。

---

## 开始之前需要什么

- 一台电脑（Windows、Mac 或 Linux）
- 一个放网站文件的文件夹（至少要有 `index.html`）
- 可选：你拥有的域名（例如 `myshop.com`）

**不需要** 会编程，也**不需要** 懂 Nginx 或 SSL 证书。

---

## 分步操作：发布第一个网站

| 步骤 | 操作 |
|------|------|
| 1 | 在桌面创建文件夹 `MyWebsite`。 |
| 2 | 把网站文件放进去（`index.html`、图片等）。 |
| 3 | 从 [GitHub](https://github.com/utahisnotastate/Utahx) 下载 Utahx，将 `utahx.cmd` 或 `utahx.exe` 放入 `MyWebsite`。 |
| 4 | 双击 Utahx 文件。 |
| 5 | 询问域名时，输入你的域名，或按 **Enter** 跳过（仅本地测试）。 |

**完成。** Utahx 会扫描文件夹、选择服务方式并启动 Web 服务器。若填写了域名，还会自动配置 HTTPS。

未填域名时，通常可通过 `http://localhost:8080` 访问。

---

## Utahx 自动为你做的事

| 功能 | 对你的意义 |
|------|------------|
| **自动识别** | 根据文件判断 HTML、Python 或 Node.js 项目 |
| **自动安全** | 提供域名后自动申请并安装 TLS 证书 |
| **流量平滑** | 访问高峰时略微延迟请求，而不是显示可怕错误 |
| **预取** | 预测你可能打开的下一页并提前加载 |
| **友好错误** | 用清晰说明代替 `502 Bad Gateway` |

---

## 常见问题

**需要写配置文件吗？**  
不需要。Utahx 刻意避免 `nginx.conf` 这类文件。

**能在公网访问吗？**  
可以：域名 DNS 指向你的服务器，并开放 80/443 端口（家庭网络可能还需路由器设置）。

**出错了怎么办？**  
Utahx 会显示通俗说明；开发者还能看到文件与行号提示。

---

## 专业说明（通俗版）

后台 Utahx 充当 **反向代理** 与 **Web 服务器**，监听标准端口 **80**（HTTP）与 **443**（HTTPS），扫描项目目录并分流访客——**无需手写配置**。
