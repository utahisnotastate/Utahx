## Стратегия

Open source снимает боль Nginx у разработчиков. **Utahx Cloud Control** монетизирует то, за что предприятия платят: видимость, глобальная политика, управляемый масштаб, поддержка.

```
Бесплатный OSS (GitHub)  →  Внедрение  →  Подписка Cloud
```

## План выхода на рынок

### Фаза 1 (недели 1–2)

1. Публикация: [github.com/utahisnotastate/Utahx](https://github.com/utahisnotastate/Utahx)  
2. Лендинг: *«Nginx устарел. Нулевая конфигурация, защита от падений.»*  
3. CTA: `git clone` + `utahx start`  
4. Демо: сравнение 502 до/после  

### Фаза 2 (недели 3–8)

- Образ Docker в GHCR  
- Контент DevRel: «Миграция за 60 секунд»  
- Обратная связь через GitHub Issues  

### Фаза 3 (месяц 3+)

- Закрытая бета дашборда Cloud  
- Ключ `UTAHX_CLOUD_API_KEY` (дорожная карта)  
- Продажи Enterprise командам на Kubernetes  

---

## Технический крючок (дорожная карта)

```bash
export UTAHX_CLOUD_API_KEY=utx_live_xxxxxxxx
utahx start --domain example.com
```

Планируемая телеметрия (анонимизированная):

- RPS и события вязкости  
- Hit rate семантического кэша  
- Статус продления TLS  
- Число подов в managed K8s

## Модель дохода

| Поток | Модель |
|-------|--------|
| Open source | MIT, без лицензионной платы |
| Cloud | Ежемесячная подписка на организацию |
| Managed cells | Перерасход за выделенные namespace K8s |
| Enterprise | Годовой контракт + поддержка + комплаенс |

---

## Позиционирование

| Конкурент | Utahx OSS | Utahx Cloud |
|-----------|-----------|-------------|
| Nginx + Certbot | Без конфига, сглаживание | Дашборд + managed scale |
| Cloudflare (частично) | Self-hosted | Гибрид edge + on-prem |
| Traefik | Проще старт | UI политик для Enterprise |
